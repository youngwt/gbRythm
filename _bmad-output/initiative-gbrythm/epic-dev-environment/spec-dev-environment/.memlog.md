- (capability) CAP-1: agent can build a Game Boy ROM from C source with one command; success: from clean checkout build exits 0 and produces a .gb file, and a deliberate C syntax error exits non-zero with the compiler message
- (capability) CAP-2: agent can run the ROM without a display and check what it did; success: scripted run loads ROM, advances frames, presses a button, saves a screenshot with no window, and exits 0/non-zero on a pass/fail check
- (capability) CAP-3: user can play the ROM in an emulator and step through its C source in VS Code; success: breakpoint on a C line stops execution and shows variable values. Kept by user despite Java setup cost; getting Java working is in scope

- (capability) CAP-5: proof ROM shows the toolchain works end to end by drawing to the screen and reacting to a button (user: draw-and-react is the bar, nothing game-like needed); success: ROM shows something on boot and visibly changes on button press, confirmed by the CAP-2 script
- (decision) Running on real hardware / flash cart purchase is out of this spec (user owns no cart yet)
- (constraint) Toolchain is GBDK-2020 4.5.0, plain, no engine; code in C (from research)
- (constraint) Target is original Game Boy (DMG); no Color-only features in the proof ROM
- (constraint) Nothing installs to the system partition: SteamOS root is read-only (verified: steamos-readonly enabled) and reset by OS updates; no Java on host or in Flatpak

- (constraint) Everything must work from the VS Code Flatpak terminal where the agent runs; tools located by explicit path or project setting, never by assuming PATH
- (constraint) Build (CAP-1) and verification (CAP-2) are command-line only and non-interactive: no window, click or prompt
- (constraint) Headless testing uses PyBoy run via uv (installed, 0.12.22); interactive debugging uses Emulicious plus its VS Code extension (from research)
- (constraint) Downloaded tool binaries are not committed to git; repo holds source, build files and setup instructions with pinned versions

- (constraint) Proof ROM is 32K or smaller with no mapper, so it runs on any flash cart later
